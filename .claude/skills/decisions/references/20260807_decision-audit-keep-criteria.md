## 결정

[20260801_decision-log-pruning-policy.md](20260801_decision-log-pruning-policy.md)(폐기·소진 문서의 삭제/디인덱스)를 확장해, **"애초에 기록 가치가 부족했던 결정"까지 걸러내는 유지 기준**을 확정한다.

**KEEP — 아래 가치 원천 중 하나라도 실질적으로 있으면 유지:**

1. **실측·실증 기록** — 도그푸딩 로그 판독, 타이밍 측정, OS/앱 동작 실증 등 재현 비용이 큰 사실
2. **기각한 대안과 그 이유** — 코드에는 채택안만 남는다. 특히 나중에 다시 시도할 법한 대안의 기각 근거
3. **아직 유효한 재검토 트리거·재개 조건**
4. **비자명한 계약·불변식의 "왜"** — 코드는 무엇(what)만 보여주고 왜 이 모양이어야 하는지는 못 보여주는 경우
5. **살아있는 supersede 체인의 마디** — 유효한 후속 문서가 전제/참조하는 배경

위 5종이 전부 없으면 DELETE(파일까지 — git 히스토리가 아카이브), 효력은 소진됐지만 실측·위험 분석 재참조 가치가 남으면 DEINDEX(파일 유지+인덱스 제외, 기존 정책 2항 그대로).

**감사 프로토콜**: 전수 감사 시 1차 판정만으로 삭제하지 않는다 — DELETE 후보는 반드시 **"삭제 반대 변호인" 관점의 독립 재검증**을 거치고, 반박되면 사용자 판단으로 넘긴다 (애매하면 삭제 반대로 기울인다 — 잘못 남긴 것보다 잘못 지운 것이 더 아프다).
