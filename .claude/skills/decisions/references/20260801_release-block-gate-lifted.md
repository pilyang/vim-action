## 결정

**릴리스 배포 금지를 해제한다.** [게이트를 M3로 옮긴 결정](20260726_release-block-gate-moves-to-m3.md)이 건 조건 — "삼킨 키가 전부 실행되는가" — 이 충족됐다. 배포의 실무 선행 조건(서명·공증)은 M6 몫이며, 이 결정은 그 착수를 막던 금지를 걷는 것이다.

옛 결정이 승계해 온 로그·계약 규칙은 그대로 유효하며 이 문서가 다시 승계한다: `.replace` 요약 로그는 개수+첫 액션 1건·DEBUG 전용(순회 로그는 탭 타임아웃, passthrough 로그는 키로거), 소비자는 `VimAction`에 exhaustive switch 금지(`default:` 흡수), 미지원 사용자 피드백이 필요해지면 채널은 로그가 아니라 UI(메뉴바·Settings)다.

## 배경·근거 (왜) — 게이트 심사 내역 (2026-08-01)

**본체 조건: 무로그 삼킴 0건 (전수 확인).** v1 어휘 전체가 실행되고(단계 1~2c), 실행되지 않는 모든 경로가 관측 가능한 로그를 남긴다 — 진짜 미구현(`daw`·`ci"`·`di(`·`yi)`·`V`→`v`)은 `미지원 액션 스킵 [family]` 요약, 걸러내기(`nonText`/`textField`/`unresolved`)는 같은 로그의 family 태그(단계 3 실기기 전수), paste의 "붙여넣을 것 없음"은 별도 자체 로그(스킵 2종 분리), 엔진 미매핑 키·pending 중간 키는 `swallow` 로그. 자동 주입 + pid 분리로 확인했다.

**안전망 회귀: 그린.** 킬스위치 배선 계약 6종 코드 대조 + 물리 검증 전 항목(발동·부활 없음·복귀·영속) 통과. 검증이 실증한 발견 2건은 수정으로 이어졌다 — [오토리핏 발동](20260801_kill-combo-autorepeat-fires.md), 그리고 아래 ④.

**위험 항목 심사 4건 (사용자 결정):**

1. **비-QWERTY `Cmd-Z`(AZERTY `Cmd-W` 데이터 손실)** → **레이아웃 가드 구현**으로 해소 ([결정](20260801_non-qwerty-command-key-layout-guard.md)). 비-QWERTY에서 문자 명령 키 합성 액션을 보류한다 — 데이터 손실 축은 문서화로 덮을 등급이 아니라는 판단.
2. **Notion `G`·`gg` 파괴적 오동작 6조합** → **수용 유지**. [기존 수용 결정](20260727_notion-cmd-shift-vertical-conflict.md) 그대로 — M4 프로파일(바로 다음 마일스톤)이 해소하며, 지금 하드코딩하면 프로파일 설계를 선취한다.
3. **킬 콤보 부분 누출**(Ctrl 늦으면 Cmd-Opt-Esc → 시스템 Force Quit 창) → **수용 확정**. Force Quit 창은 그 자체로 또 다른 구조 수단이고, 오토리핏 발동 수정으로 꾹 누르면 발동에 수렴한다.
4. **버스트 백로그 정지 지연**(게시는 즉시 끊겨도 이미 게시된 이벤트는 앱 소진까지 계속) → **스크롤 클램프 33**([결정](20260801_scroll-count-clamp-33.md))으로 최악치를 다른 어휘 수준으로 제한하고, **잔여 꼬리(~수 초)는 수용**. `chunkInterval` 튜닝은 M4 카드.

## 검토한 대안

- **백로그 완전 해소까지 게이트 유지**: 게시>소비 비대칭은 합성 이벤트 게시 모델에 내재해 Keyboard 전략에서 완전 해소가 불가능하다 — 게이트가 영구화된다. 클램프로 총량을 묶는 것이 얻을 수 있는 전부다. 기각.
- **비-QWERTY 실기기 실증까지 해제 보류**: 실증 수단(하드웨어·사용자)이 없어 무기한 보류가 된다. 가드의 실패 방향이 안전한 쪽(보류)이므로 구현+유닛 테스트로 충분하다고 판단. 기각.
